# Issue tracker: GitHub

Issues e especificações vivem em `hayashirafael/statlet`.

- Use `gh` para criar, consultar, editar e fechar issues.
- Publicar no tracker significa criar uma GitHub Issue.
- Tickets usam sub-issues e dependências nativas quando disponíveis.
- Pull requests não entram automaticamente na fila de triagem.
- Antes de qualquer escrita, confirme que a conta ativa é `hayashirafael`.

# Statlet v1.0.0

Primeira versão pública do monitor local e compacto para a menu bar do macOS.

> **Gate de distribuição:** esta publicação inicial possui assinatura ad hoc de hardened runtime, mas não possui Developer ID nem notarização porque nenhuma identidade Apple válida ou credencial notarial está configurada. O Gatekeeper pode bloquear o app baixado. Não desative o Gatekeeper nem remova a quarentena; para avaliar esta versão antes de uma build notarizada, prefira compilar e verificar o código-fonte revisado.

## Destaques

- CPU global e RAM útil em duas linhas dentro de um único item da menu bar.
- Memory pressure do macOS refletida na apresentação de RAM.
- Integração opcional do disco, com limite configurável, debounce contínuo de cinco minutos e uma notificação por episódio.
- Revisão de espaço nativa e encaminhamento explícito para o fluxo interativo do Mole no Terminal; nenhuma limpeza é executada no Statlet.
- Histórico local dos 30 eventos mais recentes, sem nomes nem caminhos de arquivos.
- Janelas reutilizáveis, labels de acessibilidade, badges simbólicos e lifecycle resistente a sleep/wake.
- Bundle Apple Silicon para macOS 14+, privacy manifest, LICENSE, NOTICE e inventário de licenças transitivas distribuídos.

## Segurança

O Statlet não executa `mo clean` silenciosamente, não solicita `sudo`, não instala o Mole e não atribui ao app limpezas feitas externamente. Uma integração destrutiva continua bloqueada até o Mole oferecer um contrato estruturado, versionado e restrito ao usuário.

## Artefatos

- `Statlet-v1.0.0-macos-arm64.zip`
- `Statlet-v1.0.0-macos-arm64.zip.sha256`

Confira o estado de Developer ID/notarização descrito na própria release antes de instalar. Valide sempre o SHA-256; não contorne o Gatekeeper para abrir uma build não notarizada.

## Compilar da fonte

Com Rust 1.89 ou mais recente e as Command Line Tools do Xcode instaladas:

```bash
git checkout v1.0.0
bash tests/package_contract.sh
```

O contrato recompila o app, valida versão, target macOS 14, arquitetura arm64, privacy manifest, assinatura local, recursos, ZIP extraído e checksum.

## Requisitos

- Mac com Apple Silicon.
- macOS 14 Sonoma ou mais recente.
- Mole 1.x compatível apenas para a ação opcional de abrir seu fluxo oficial no Terminal.
